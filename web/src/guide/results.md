# 运行结果与数据留存

节点状态包括等待、运行、完成、暂停与失败。降级表示实际应答模型不是首选模型；应同时查看失败尝试、最终模型和结构校验结果。

完整输入是节点实际消费的投影；输出、报告、diff 和哈希状态是运行证据。哈希通过只证明字节未静默变化，不证明结论正确。agent 在当前 RC 中不会生成生产报告或 diff；不要把预演结构当成执行结果。

`runs/<run-id>` 可能包含完整任务、prompt、源码、模型输出、diff、哈希和人工决定。它默认被 Git 忽略，但未加密、未自动脱敏、也没有自动保留期。分享、备份或删除前应按数据敏感性人工处理。
