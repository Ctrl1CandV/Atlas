## 第二梯队(P1,已设计、待实施——稳定性收尾)

### 2a. 拒绝性错误削减(源自 PLAN-rejection-reduction,五项全部零额外成本、不改失败语义)

实测背景:08-22 一天内三次真实失败——推理模型烧尽输出预算被截断、glm 返回非合法 JSON、费率全 null 时成本帽只放行首节点。这直接回答"工作流出错能否尽可能避免"。

| 项 | 方案 | 验收 |
|---|---|---|
| A1 | providers.json 给 Deepseek 补 `maxOutputTokens: 16384` 供应商级默认 | 同形状图不再 `output_truncated`(真实运行验证,非推断) |
| A2 | dry-run 对"推理型 + token 上限偏低"节点发醒目警告(用已探测能力数据;未探测不警告) | 警告出现在 dry-run 返回;六示例离线行为不回退 |
| B1 | 同一响应宽容提取:严格解析失败后剥围栏取最外层 JSON,记 `output_json_recovered` 事件,产物仍存原始字节 | 事件可查且 fold 不变终态;含"提取后仍缺字段→照常 DegradedOutput"反例测试 |
| B3 | 指南把"结构化审查节点配跨厂商 fallback(qwen3.8-max 实测稳定)"写成默认建议 | 指南+skill 同步 |
| C1 | dry-run 显式警告"设了 max_cost_usd 但 N 节点费率未知→只放行首个计费节点" | 警告出现在 dry-run 返回 |
| C2 | pricing.json 填入确认过的真实单价 | **只能由用户完成,不填猜的数字** |

开工顺序(2026-08-23 确认):① B1(纯代码+测试,先立"提取后仍缺必填字段照样 DegradedOutput"反例)→ ② A1+A2 同批(供应商级默认值 + dry-run 警告,警告逻辑与输出处理同域)→ ③ C1(费率警告)→ ④ B3(指南/skill 默认建议)。除 A1 验收需一次真实运行外全部零成本;真实运行按成本红线执行:先 dry-run、显式预算、便宜模型、retry=0。C2 在 A1 验收后由用户择机完成。

### 2b. 体验与技术债(审查发现,按收益排序)

| 项 | 问题 | 方案 | 工作量 |
|---|---|---|---|
| 预留额展示 | `outstanding_reserved_usd` 后端有、UI 不显示 | 成本指标旁加"已预留"项,含 * 号语义引导 | 小 |
| 跨入口运行刷新 | MCP/他标签页发起的运行不自动出现在列表 | 轮询或 SSE 广播 run 列表变更 | 小 |
| 事件流窗口 | UI 只留最近 200 条,长跑历史不可见 | 事件流尾部加"查看完整账本"入口(下载/过滤) | 小 |
| agents.json 盲区 | 设置页对生产 agent 配置只字未提 | 至少加状态卡片(是否启用/预检结果),编辑仍走文件 | 中 |
| 熔断不持久 | Web 重启熔断清零 | 按供应商落 runs 外的本地状态文件;或如实文档化 | 中 |
| 无并发上限 | 并行度完全交给执行器 | guards 加 `max_parallelism`(先 RFC:与超步语义的交互) | 中,需 RFC |
| 账本 16MiB 硬顶 | 接近上限时全量读秒级 IO,到顶杀 run | 分段账本+索引;或先做运营指南(何时清理) | 中 |
| 参数不核对 | seed/temperature 只进请求体 | 响应回显核对(能核的核,不能核的标注) | 小 |
| CLI 契约脆弱 | claude --help 排版变化会误判 | 契约探测加版本锁定+失败时明确报错 | 小 |
| 非产品恢复路径 | `_resume_graph_replay` 可被外部误用绕过准入 | 收敛为测试专用或删除 | 小 |
| 死占位 | `_NODE_FACTORIES` 的 None 占位与真实分发可能漂移 | 统一分发入口 | 小 |
