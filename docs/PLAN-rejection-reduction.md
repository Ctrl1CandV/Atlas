# 减少拒绝性错误的方案（截断 / 非法 JSON / 成本帽拦截）

> 状态：提案,2026-08-22。本文记录方案与决策请求,不是已实施能力。全部依据当天真实运行的账本证据;每项落地前不改任何守卫的失败语义。
>
> 背景:2026-08-22 用真实供应商跑示例图与自定义图,连续三次被 Atlas 自身的防护拒绝。这些拒绝都是**正确行为**(拦住了退化输出),但其中两类本可以在更早、更便宜的阶段避免。本文目标:把"跑起来才发现"变成"预演时就知道",并减少不必要的整图失败。

## 0. 实测证据

| 运行 | 拒绝点 | 账本事件 |
|---|---|---|
| `20260822-112853-9a5a26` | author 节点输出达 8192 上限被截断 → DegradedOutput → 无备用链 → AllCandidatesFailed | `output_truncated` + `model_failed` |
| `20260822-113040-188a83` | reviewer(glm-5.3)返回非合法 JSON → 必填字段解析失败 → 同上 | `model_failed: 返回不是合法 JSON:Expecting value` |

## 1. 截断类(推理模型烧尽输出预算)

**根因**:推理型模型的隐性思考消耗 `max_output_tokens`;deepseek-v4-flash 默认 8192 时,长文本节点的可见输出被截断。CHANGELOG 已记录"16384 后正常"的先例。

| 选项 | 内容 | 成本 | 风险 |
|---|---|---|---|
| A1 | `config/providers.json` 给 Deepseek 补供应商级 `maxOutputTokens: 16384` 默认(与 SuperAI 现有配置同型) | 零(纯配置) | 无;单节点仍可用更小值覆盖 |
| A2 | dry-run/预览利用 `thinking.py` 已探测的能力数据,对"推理型 + `max_output_tokens` 偏低"的节点发醒目警告 | 零 | 低;未探测模型不警告(诚实现状) |
| A3 | 截断失败后自动升档 token 上限重试一次 | 每次截断多一次调用费 | **改重试语义,需先小 RFC**:自动加钱必须显式决策,不能静默 |

## 2. 非法 JSON 类(结构化输出被围栏/散文包裹)

**根因**:部分模型在要求"只输出 JSON"时仍包裹 markdown 围栏或前后缀文字;当前解析严格失败,等价于把格式方差当成内容退化。

| 选项 | 内容 | 成本 | 风险 |
|---|---|---|---|
| B1 | 对**同一份响应**做宽容提取:严格解析失败后,剥代码围栏、取最外层 JSON 对象,再走必填字段检查;成功记显式事件(如 `output_json_recovered`),产物仍存原始字节 | 零(不发生新调用) | 中:必须保持可见性——事件+摘要标注"经提取恢复",不冒充严格解析 |
| B2 | 按节点启用供应商 `response_format: json_object` | 每次调用同价 | 各网关支持参差,需实测矩阵后定 |
| B3 | 指南把"结构化审查节点配跨厂商 fallback"写成默认建议(实测 qwen3.8-max 稳定) | 零 | 无 |

## 3. 成本帽拦截类(费率未知 + 帽 = 只放行首节点)

**根因**:P0min 合同——费率未知时保守占满剩余预算,防止无法证明不超支。多节点图在 pricing 全 null 时必然在第二个计费节点被拒。这是**正确语义**,问题只在暴露时机。

| 选项 | 内容 | 成本 | 风险 |
|---|---|---|---|
| C1 | dry-run 显式警告:"设了 max_cost_usd 但 N 个节点费率未知,守卫将保守占满预算,实际只放行首个计费节点" | 零 | 无;纯信息前置 |
| C2 | 在 `config/pricing.json` 填入**确认过**的真实单价 | 零 | 纪律红线:不填猜的数字,此步只能由用户完成 |

## 4. 建议与决策请求

**建议立即实施**(全部零额外成本、不改守卫失败语义):A1、A2、B1、B3、C1。

**需要决策**:A3(截断自动升档重试)与 B2(供应商 JSON 模式)各自立项小 RFC,不与本批捆绑。

**验收基线**:
- A2/C1 的警告出现在 dry-run 返回中,且 six 示例工作流离线 dry-run 行为不回退;
- B1 恢复的事件在账本可查,`fold_events` 不因新事件类型改变终态;
- A1 生效后同形状图在 8192→16384 下不再触发 `output_truncated`(以真实运行验证,非推断);
- 每项补 Python 测试;B1 需含"提取后仍缺必填字段 → 照常 DegradedOutput"的反例。
